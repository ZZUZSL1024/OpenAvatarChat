# 实时语音打断能力说明

## 功能概述
- 当数字人正在回答时，如果客户端发送新的聊天请求（文本或语音触发的 `chat` 消息），或者显式发送 `stop_chat` 指令，后端会立即向会话广播 `interrupt` 信号。
- 会话收到中断信号后会：
  - 重新允许 VAD 检测新的用户语音输入；
  - 清空各 handler 的输入队列以及数据分发队列，停止当前回答音频/视频的继续播放或排队。

## 使用方式
1. 客户端侧在用户开始新的提问时，通过 RTC DataChannel 发送类型为 `chat` 的消息（现有文本输入逻辑已包含），或在需要强制打断时发送 `stop_chat` 消息。
2. 服务器收到消息会触发中断，立即停止当前回答并准备处理新的问题。
3. 若需要自定义客户端行为，可在前端监听 `avatar_end` 提示并在发送新问题前主动发送 `stop_chat`，以确保更快的打断体验。

## 影响范围
- 新增的中断处理仅影响当前会话的队列，不会关闭会话或销毁资源。
- 其他处理流程保持不变，兼容现有的 VAD/ASR 语音管线。
